Accepted-Link Setter Guide

How to build a SudokuMaker link gridfind will accept — every table on this page is generated from the decoder itself, so it can never disagree with what the code does.

What This Guide Covers

An accepted link is a SudokuMaker share URL that gridfind can decode into a puzzle and judge found, broke, or unknown. This page describes the current link form and how to build one: you draw the grid and its constraints in SudokuMaker, and you declare a doubler or a Schrödinger cell by drawing a cosmetic cage with a recognized name (the cage-name table below).

Every reference table here is generated from the decoder itself, so it states exactly what gridfind accepts today — the tables cannot drift from the code. For the byte-level wire format behind each block — how a constraint is encoded in the URL — see the link-format reference, research/sudoku-link-formats.md; this guide never repeats those internals.

How gridfind Reads The Position

gridfind reads each cell's contents as the state under test — the position it must judge. Three cell states carry meaning; everything else is ignored.

SudokuMaker cellRead asMeaning
A given digitGivenA setter clue fixed on the puzzle.
A placed value (not given)PlacementA solver's placement in the position being tested.
Center pencilmarksCandidatesThe digits still allowed in that cell; only digits in the board's domain survive.
Corner pencilmarks, cell colors, an empty cellIgnoredNo gridfind equivalent — dropped.

A cell inside a Schrödinger marker cage is read differently: the marker cage's own value selects its directive. The cell's center pencilmarks, if any, only restrict that directive afterward — narrowing which digits the S-cell may hold — they never choose pin, half-pin, or bare on their own.

Marker-cage valueDirectiveMeaning
Names two digits (e.g. "4,7")PinThe S-cell is pinned to that digit pair.
Names one digit (e.g. "4")Half-pinThe S-cell is known to hold that digit; its partner is free.
Absent, empty, or unparseableBareBoth of the S-cell's digits are free.

Center pencilmarks drawn on a caged cell are optional and layer a consistency check on top of the cage's directive — a pin needs the marks to contain its pair, a half-pin needs its known digit marked among at least two marks, and a bare needs at least two marks to draw the pair from. They never override which directive the cage's value selected.

A cell carrying a settled value cannot also be an S-cell: a value on a cell inside a Schrödinger marker cage is a contradiction, and gridfind rejects the link (see Troubleshooting).

Other Board Sizes

gridfind decodes any square board. Boxes are a convention only for the sizes in the table above: on a 4×4, 6×6, or 9×9, a plain regions block stands for the standard boxes. Any other square size decodes only with its own regions — gridfind has no box geometry to supply, so you must draw an explicit region partition, or the board runs as rows-and-columns only.

To draw those regions, use SudokuMaker's regions tool. Needs confirmation against live SudokuMaker

Drawing Each Constraint In SudokuMaker

What to draw in SudokuMaker to produce each supported constraint (fact a). The wire block, decode result, and accept/ignore/reject verdict for each are in the reference below.

White Kropki (Difference Dot) — Place a white dot on the edge between two orthogonally adjacent cells.

Black Kropki (Ratio Dot) — Place a black dot on the edge between two orthogonally adjacent cells.

XV — Place an X (=10) or a V (=5) clue on the edge between two orthogonally adjacent cells.

Thermometer — Draw a thermometer line with SudokuMaker's thermometer tool, from the bulb outward. Its slow toggle sets the non-strict variant.

Renban Line — Draw a line with SudokuMaker's renban tool; its cells must hold a run of consecutive, non-repeating digits in any order. Exact tool name/location needs confirmation against live SudokuMaker

Whisper Line (German/Dutch) — Draw a line with SudokuMaker's whisper tool and set its minimum-difference threshold (German is 5, Dutch is 4). Exact tool name/location needs confirmation against live SudokuMaker

Palindrome Line — Draw a line with SudokuMaker's palindrome tool; its digits must read the same forwards and backwards. Exact tool name/location needs confirmation against live SudokuMaker

Between Line — Draw a line with SudokuMaker's between-line tool, circling the two bulb ends; every cell between them must hold a digit strictly between the two bulb values. Exact tool name/location needs confirmation against live SudokuMaker

Lockout Line — Draw a line with SudokuMaker's lockout-line tool, circling the two bulb ends; the bulbs must differ by at least size//2 and every cell between them must hold a digit strictly outside the bulb interval. Exact tool name/location needs confirmation against live SudokuMaker

Double-Arrow Line — Draw a line with SudokuMaker's double-arrow tool, circling the two bulb ends; the digits on the cells between them must sum to the sum of the two bulb values. Exact tool name/location needs confirmation against live SudokuMaker

Grouped Line (Entropic/Modular/Parity) — Draw a line with SudokuMaker's entropic, modular, or parity tool; every window of consecutive cells the size of the tool's group count must hold one digit from each group. Exact tool name/location and the type 406 groups wire shape need confirmation against live SudokuMaker

Extra Region (Windoku) — Mark a group of cells with SudokuMaker's extra-region tool; each marked group must hold all-different digits. Exact tool name/location needs confirmation against live SudokuMaker

Row Indexing (159) — Mark cells with SudokuMaker's indexing tool set to the row-index mode. Which tool mode is type 600 vs. 601 needs confirmation against live SudokuMaker

Column Indexing (159) — Mark cells with SudokuMaker's indexing tool set to the column-index mode. Which tool mode is type 600 vs. 601 needs confirmation against live SudokuMaker

Even — Mark a cell with SudokuMaker's even/odd tool set to even. Exact tool name/location needs confirmation against live SudokuMaker

Odd — Mark a cell with SudokuMaker's even/odd tool set to odd. Exact tool name/location needs confirmation against live SudokuMaker

Quadruple — Place a quadruple clue at the intersection of four cells with SudokuMaker's quadruple tool, and type the required digits. Exact tool name/location needs confirmation against live SudokuMaker

Clone — Mark two or more groups of cells with SudokuMaker's clone tool; the cells of each group must hold identical digits. Exact tool name/location and the type 302 input.groups wire shape need confirmation against live SudokuMaker

Killer Cage — Draw a cage with SudokuMaker's killer-cage tool. Type a cage sum if you want one; leave it blank for a no-sum cage.

Cosmetic Cage — Draw a cage with SudokuMaker's cosmetic (decoration) tool. Type a numeric label to make it a sum cage. To declare a marker instead, name the cage Doubler, S-cell, or Schrödinger over the cells it marks. Naming step needs confirmation against live SudokuMaker

Anti-Knight — Enable the anti-knight global constraint, so no two cells a knight's move apart share a digit. Toggle location needs confirmation against live SudokuMaker

Anti-King — Enable the anti-king global constraint, so no two cells a king's move apart share a digit. Toggle location needs confirmation against live SudokuMaker

Negative Diagonal (\) — Enable the negative-diagonal (\) global constraint. Enable it together with the positive diagonal for X-sudoku. Toggle location needs confirmation against live SudokuMaker

Positive Diagonal (/) — Enable the positive-diagonal (/) global constraint. Enable it together with the negative diagonal for X-sudoku. Toggle location needs confirmation against live SudokuMaker

Per-Constraint Reference

White Kropki (Difference Dot)

Wire block
type 200 {clues:[{value, edge}], negative:[…]}
Decodes to
One pair-difference Constraint per clue; value maps verbatim to diff. A non-empty negative list adds one negated pair-difference per listed value, over every orthogonally-adjacent pair not already carrying a dot.
Verdict
Accept the positive clues and enforce a non-empty negative list. An edge naming no in-bounds pair raises ValueError. disabled blocks are skipped.

Black Kropki (Ratio Dot)

Wire block
type 201 {clues:[{value, edge}], negative:[…]} — same shape as white kropki.
Decodes to
One pair-ratio Constraint per clue; value maps verbatim to k.
Verdict
Accept the positive clues; negative is warn-and-dropped. A non-integer value raises ValueError, as does an out-of-range edge. disabled blocks are skipped.

XV

Wire block
type 202 {clues:[{value, edge}], negative:[…]} — value is 10 (X) or 5 (V).
Decodes to
One aliased group-sum Constraint per clue: 10 selects the X alias, 5 the V alias.
Verdict
Accept clues whose value is 10 or 5; any other value raises ValueError. negative is warn-and-dropped; disabled blocks are skipped.

Killer Cage

Wire block
type 301 {cages:[{cells, value}]}.
Decodes to
Each cage becomes a no-repeats cage Constraint; a positive value additionally emits a group-sum over the same cells.
Verdict
Accept. value 0 or absent is SudokuMaker's own no-sum cage — cage alone, no group-sum. disabled blocks are skipped; an empty cages list adds nothing.

Cosmetic Cage

Wire block
type 2001 {cages:[{value:str, cells}], name?, style?} — value is a string; a top-level name may mark the block as a variant declaration.
Decodes to
name classifies the block: Sum/Killer decodes as a killer cage (a numeric non-zero string value graduates to a group-sum); Doubler emits per-cell modifier directives; S-cell/Schrödinger/Schrodinger infers Schrödinger-ness and routes its cells through the per-cell S-cell branch; absent or unrecognized carries no rule.
Verdict
Accept a recognized name. An unnamed or unrecognized name is warn-and-dropped to stderr, naming the block. disabled blocks are skipped.

Thermometer

Wire block
type 300 {slow:bool, thermometers:[[cell indices, bulb first], …]}.
Decodes to
One thermo Constraint per path, order preserved (bulb first); slow rides onto every path in the block.
Verdict
Accept. disabled blocks are skipped; an empty thermometers list adds nothing.

Extra Region (Windoku)

Wire block
type 305 {cells:[…]}.
Decodes to
One extra-region Constraint per block, carrying every marked cell's address. Reuses the same DistinctOverGroups rule rows/cols/regions ride: several blocks each contribute one group to a single combined all-different partition.
Verdict
Accept. disabled blocks are skipped; a block with no usable cells is warn-and-dropped to stderr.

Row Indexing (159)

Wire block
type 600 {cells:[…], style?} — style is cosmetic.
Decodes to
One indexing Constraint per block, axis "row", carrying every marked cell's address. Each marked cell (R,C) states (V,C)=R for its placed digit V.
Verdict
Accept. disabled blocks are skipped; a block with no usable cells is warn-and-dropped to stderr.

Column Indexing (159)

Wire block
type 601 {cells:[…], style?} — style is cosmetic, same shape as row indexing.
Decodes to
One indexing Constraint per block, axis "col", carrying every marked cell's address. Each marked cell (R,C) states (R,V)=C for its placed digit V.
Verdict
Accept. disabled blocks are skipped; a block with no usable cells is warn-and-dropped to stderr.

Even

Wire block
type 100 {cells:[…], style?} — style is cosmetic, same shape as row/column indexing.
Decodes to
One parity Constraint per block, parity "even", carrying every marked cell's address. Reads value mode: 2·d over a doubler, combined s_value over an S-cell, the bare digit otherwise — so a doubled cell is always even.
Verdict
Accept. disabled blocks are skipped; a block with no usable cells is warn-and-dropped to stderr.

Odd

Wire block
type 101 {cells:[…], style?} — style is cosmetic, same shape as even.
Decodes to
One parity Constraint per block, parity "odd", carrying every marked cell's address. Reads the same value mode as even — so a doubled cell is never odd, unsatisfiable.
Verdict
Accept. disabled blocks are skipped; a block with no usable cells is warn-and-dropped to stderr.

Quadruple

Wire block
type 303 {clues:[{corner, digits}]}.
Decodes to
One quadruple Constraint per clue: corner resolves to its 2x2 block's four cells; each of digits must equal at least one of those cells' values (2·d over a doubler, combined s_value over an S-cell, the bare digit otherwise).
Verdict
Accept. disabled blocks are skipped.

Clone

Wire block
type 302 {input:{groups:[{cells}]}}.
Decodes to
One clone Constraint per group of two or more cells: the cells of a group must hold equal digit sets — digits only, never the modifier marking (a cloned cell does not inherit its source's doubler/constant), read through real_digit_slots so two S-cells compare their unordered pairs.
Verdict
Accept. A group with fewer than two cells, and a disabled block, are skipped.

Renban Line

Wire block
type 400 {lines:[[cell indices, ordered], …]}.
Decodes to
One line Constraint per path, relation "renban", order preserved; no extra block param. Every real digit slot on the path (both of a Schrödinger cell's, gated by real_digit_slots) must be distinct, and the run's spread must equal one less than however many real slots the path carries — a consecutive, non-repeating run the line enforces on its own, off any box/region.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing.

Whisper Line (German/Dutch)

Wire block
type 401 {lines:[[cell indices, ordered], …], minDifference:int}.
Decodes to
One line Constraint per path, relation "whisper", order preserved; minDifference rides onto every path in the block. Each adjacent pair's values (2·d over a doubler, combined s_value over an S-cell, the bare digit otherwise) must differ by at least minDifference.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing. A block missing minDifference raises KeyError — no invented default.

Palindrome Line

Wire block
type 402 {lines:[[cell indices, ordered], …]}.
Decodes to
One line Constraint per path, relation "palindrome", order preserved; no extra block param. Each mirror pair (i, n-1-i) must hold the same real digit (real_digit_slots); an odd-length path's middle cell is free. A Schrödinger-widened path cell has no defined mirror-pair fold and raises loud rather than guess one.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing.

Between Line

Wire block
type 403 {lines:[[cell indices, ordered], …]}.
Decodes to
One line Constraint per path, relation "between", order preserved; no extra block param. The two path ends are the bulbs (value_expr — 2·d over a doubler, combined s_value over an S-cell); every interior cell's value must sit strictly between them. The bulbs only bound each other; a 2-cell path (no interior cell) asserts nothing.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing.

Grouped Line (Entropic/Modular/Parity)

Wire block
type 406 {lines:[[cell indices, ordered], …], groups:[bitmask, …]} — groups rides onto every path in the block.
Decodes to
One line Constraint per path, relation "grouped", order preserved; groups rides through verbatim. Every window of len(groups) consecutive path cells (real_digit_slots, folded like palindrome) must hold one digit from each group — entropic, modular, and parity all ride this one rule, keyed only by which groups they name.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing. A block missing groups raises KeyError — no invented default. groups that leave a gap or overlap the board's digits raise MalformedPuzzleError. A Schrödinger-widened path cell has no defined single-window fold and raises loud rather than guess one.

Lockout Line

Wire block
type 407 {lines:[[cell indices, ordered], …]}.
Decodes to
One line Constraint per path, relation "lockout", order preserved; no extra block param. The two path ends are the bulbs (value_expr — 2·d over a doubler, combined s_value over an S-cell); they must differ by at least size//2 (from the board's own size, never the wire); every interior cell's value must sit strictly outside the closed bulb interval.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing.

Double-Arrow Line

Wire block
type 409 {lines:[[cell indices, ordered], …]}.
Decodes to
One line Constraint per path, relation "double-arrow", order preserved; no extra block param. The two path ends are the bulbs (value_expr — 2·d over a doubler, combined s_value over an S-cell); the interior cells' values must sum to the bulbs' own sum. Reversal-invariant; a 2-cell path (no interior) is naturally broke, since an empty interior sums to 0.
Verdict
Accept. disabled blocks are skipped; an empty lines list adds nothing.

Negative Diagonal (\)

Wire block
type 10 {style?} — a bare toggle; style is cosmetic.
Decodes to
One negative-diagonal Constraint: the `\` diagonal holds all-different digits. Independent of the positive diagonal.
Verdict
Accept an enabled block. A disabled block is skipped; the cosmetic style is ignored.

Positive Diagonal (/)

Wire block
type 11 {style?} — a bare toggle; style is cosmetic.
Decodes to
One positive-diagonal Constraint: the `/` diagonal holds all-different digits. Both toggles together are X-sudoku.
Verdict
Accept an enabled block. A disabled block is skipped; the cosmetic style is ignored.

Anti-King

Wire block
type 12 — a bare toggle, no payload.
Decodes to
One anti-king Constraint: no two cells a king's step apart share a digit.
Verdict
Accept an enabled block. A disabled block is skipped.

Anti-Knight

Wire block
type 13 — a bare toggle, no payload.
Decodes to
One anti-knight Constraint: no two cells a knight's hop apart share a digit.
Verdict
Accept an enabled block. A disabled block is skipped.

When A Link Is Ignored Or Rejected

gridfind puts each block on one of three outcomes: it accepts the rule (emits it), ignores the block (silently, or with a warning), or rejects the whole link.

Ignored silently

A block you switched off in SudokuMaker (a disabled block) is not part of the puzzle. gridfind skips it with no warning, even for a constraint type it would otherwise decode. A link may safely carry a disabled duplicate beside a live block.

Ignored with a warning

Some blocks are dropped but announced on standard error, so a verdict is never computed silently under a smaller ruleset than the link states:

  • A constraint type gridfind does not model, carrying real data, is dropped with a warning naming it. An empty or decoration-only block of an unmodeled type is dropped quietly.

Rejected outright

A rejected link produces no puzzle at all — gridfind raises an error before it builds one, because it found a link it cannot support. Common causes:

  • A cosmetic cage named with anything other than a recognized name (the table above).
  • A cell that both holds a value and sits inside a Schrödinger marker cage.
  • An XV clue whose value is neither 10 (X) nor 5 (V).
  • A black-kropki dot whose ratio label is not a whole number.
  • A dot, X, or V whose edge names no valid pair of adjacent cells on the board.
  • A non-square grid, a cell count that does not match the declared size, or a digit domain whose width is not the board size.

A link that decodes but describes an impossible puzzle — a broken region partition, a domain the placements violate — is not rejected here. It becomes a puzzle, and the contradiction surfaces later, at verdict time. Only a rejected link means the link itself is unsupported.
